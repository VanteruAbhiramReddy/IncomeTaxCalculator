INCOME TAX ESTIMATOR
=============================

Requirements:
- JDK installed (javac and java available in the terminal).

Compile:
Open a terminal in the PayrollIncomeTaxEstimator_Rs project folder and run:

    javac -d out src/com/model/*.java src/com/util/*.java src/Main.java

Run:
    java -cp out Main

Choose:
1 = Salary/job (Sections 44AD and 44ADA do not apply)
2 = Eligible business (illustrative Section 44AD calculation)
3 = Specified profession (illustrative Section 44ADA calculation)
